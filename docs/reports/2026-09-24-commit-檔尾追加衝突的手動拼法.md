# commit.md：檔尾追加衝突的手動拼法

# Description

- sparktoy-erp 的 `/wrap-up` Quick 提交時，`docs/spec/schemas.md` 尾端有兩段未提交的追加：另一個 session 的「商品上架」段落，緊接著本 session 的「文字匯入」段落。
- `session-log.py writes --mine <file> --stage` 因兩段相鄰回報 conflict，不 stage；commit.md 只說「resolve by hand」，現場才想出拼法。

# Changes Made

- `skills/wrap-up/commit.md`：conflict 那句後補一句常見情況的做法——`git show HEAD:<file>` ＋ 只加自己那段 → `git hash-object -w` ＋ `git update-index --cacheinfo` → 不帶 pathspec commit。

# Result

- 下次遇到「兩個 session 都在檔尾追加」的衝突，照一句話就能只提交自己那段，不必走 cp／還原的手動路線。
