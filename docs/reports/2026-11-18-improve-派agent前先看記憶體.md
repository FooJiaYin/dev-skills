# improve：派 agent 前先看記憶體、長指令輸出先存檔

日期：2026-11-18｜來源 session：pimi-launch-implementation（58181c4a-342a-4e35-a066-7c40b519c198）｜專案：pimi

## 改了什麼

| 檔案 | 修改 |
|---|---|
| `docs/agents-and-sessions.md`「派 agent 之前」 | 新增兩條：派會跑測試、build 或起服務的 agent 前先看記憶體與 swap 再定平行上限，吃資源的驗證不和其他 agent 同時跑；跑很久的指令輸出先存檔再篩選 |
| `~/.claude/CLAUDE.md`（不在這個 repo） | 「TODO.md 跟著進度更新」補一句：對使用者說出「請你決定／我先暫定」的同一步就寫進 TODO.md |

## 為什麼

| 出錯的步驟 | 後果 |
|---|---|
| 在 8 GB 的機器上沒看記憶體就同時派 4–6 個會跑整合測試的 agent，還讓一個 agent 在本機 build Docker 映像 | swap 用到 12 GB；同一支測試從 2 分 17 秒變 11 分 19 秒；本機 Postgres 當掉一次；使用者問了兩次為什麼這麼久，最後自己去關其他程式 |
| 一支 10 分鐘的測試，輸出直接接 `grep … \| head -8` | 摘要行被前 8 行雜訊擠掉，結果未知，只能換方法重驗 |
| 口頭說了十幾項「請你決定／先暫定」，沒有當下寫進 TODO.md | 使用者問「待決定項目都有在 TODO.md 嗎」，對出漏 6 項 |

## 這次沒有寫成規則的

- 「從使用者的一句話推導出固定做法前先講代價、等點頭」：使用者選擇只修正那則存錯的專案筆記，不加全域規則。
- 整合測試的寫法（一個功能區一個檔、共用資料放 `beforeAll`）：屬於 pimi 專案，等實際計時後寫進該專案的 `backend/AGENTS.md`。
