# Material Design｜柔和色塊與圓角模組

原圖：[日誌與睡眠 dashboard](images/material-wellness.png)、[教育 dashboard](images/material-learning.png)。

保留使用者提供的風格名稱。這組圖以 opaque pastel / rounded modular UI 為主要視覺語言；不是官方 Material 規範的完整對照、特定版本認證或 library 整合證明。

## 圖片觀察

- 日誌圖：淡紫、鼠尾草綠及白色的大圓角區塊；白色膠囊輸入、近黑主操作。模組靠實色區分，邊框與陰影很輕。
- 教育圖：暖白背景、窄垂直導覽、大字標題與彩色內容卡；圓形圖示底座、膠囊分類，大小不同的模組建立主次。
- 核心是「色塊與容器」承接任務，與極簡的無容器、玻璃的透光重疊都不同。

## 建議 style tokens（非原圖量測）

| 項目 | 建議起點 |
|---|---|
| 背景 | 暖白 `#F7F5F2` 或淺灰 `#EEEDEB` |
| Surface | 淡紫 `#DCD7F4`、鼠尾草綠 `#C9DED0`、奶油杏 `#F8DFC0`、柔粉 `#F1CCCC`；單一畫面選 2–3 色 |
| 色彩分工 | 色彩對應功能或狀態，如紫色 AI 引導、綠色分鏡／已選內容、杏色模板探索；不是任意彩色裝飾 |
| Border | 大多無邊框；必要分隔 `1px solid rgba(32,34,39,.10)` |
| Radius | 主模組 `24–32px`；內部卡片 `16–20px`；縮圖 `12px`；操作、輸入與分類 chip 採膠囊形 |
| Shadow | 多數模組無陰影；浮起面板 `0 8px 24px rgba(32,34,39,.06)` |
| Material | 不透明、霧面實色；無透光邊、blur、漸層光暈 |
| Spacing | 8px 基準；模組間距 `16–24px`；內距 `24–32px`；相關控制 `8–12px` |
| Font | Manrope（英文）／Noto Sans TC（中文）；內文 400–500，標題 600；圓潤但不幼稚 |
| Type scale | 頁面標題 `32–40px`；模組標題 `22–26px`；選項 `16–18px`；內文 `14px`；標籤 `12px` |
| Text | 主要 `#202227`；次要 `#61636B`；彩色底仍使用深色文字 |
| Icon | `22–24px`，`1.75–2px` 線寬；比極簡版更有份量，可放進白色圓形底座 |
| Primary action | 近黑底＋白字的膠囊，`44–48px` 高；同區只一個主要操作 |
| Selection | 選項整體底色變化＋勾選／狀態標籤；不要只靠一條細邊框 |

## 構圖應用

- 使用不對稱模組，而不是固定三欄編輯器換成粉彩。作品預覽最大，AI 引導為次主模組，模板與分鏡是較小輔助模組。
- AI 模組可以淡紫底，內部白色選項列、近黑選中項。不要再在選項內嵌另一層彩色卡片。
- 模板頁用圖片＋用途與素材需求組成卡片；分類 chip 與主操作有明確深淺差別。
- 大字標題與深色按鈕提供焦點，柔色容器負責分組；避免全畫面一樣重。

## 常見失敗與檢查

- 失敗：所有元素同樣大圓角、隨機彩虹卡片、每層都加陰影、彩色卡內再套多層彩色卡、把 Material 誤做 neumorphism。
- 檢查：每種色塊能否說出功能？不用陰影仍分得清主次嗎？主要操作是否比裝飾更容易辨認？
- 尊重實際品牌：此圖庫是可選的粉彩分支，不把所有 Material 專案都鎖成這套色票。
