# Light minimalist with line icons｜淺色極簡＋線條圖示

別名：Light simplicity、白色極簡、Camera UI。原圖：[手機照片編輯器](images/light-photo-editor.png)、[相機 UI](images/light-camera.png)。

## 圖片觀察

- 手機照片編輯器：白色工具區搭配大幅照片，細線圖示與輕量滑桿，粉色僅標示選中工具或調整值。外側大圓角是裝置殼，不是每個元件都用大圓角。
- 相機 UI：大片留白、照片矩形、直接放在白底上的線條工具、精細尺規／裁切框與少量藍色狀態。只有獨立面板有淡陰影。
- 核心是「留白、對齊與精準線條」。白色卡片堆疊或白色版本的三欄 dashboard 不等於這種極簡。

## 建議 style tokens（非原圖量測）

| 項目 | 建議起點 |
|---|---|
| 背景 | 畫布 `#F5F6F7`；面板 `#FFFFFF`；作品本身提供主要色彩 |
| Accent | 藍色 `#2F78C4`；若採照片編輯器的粉色方向，整套改為粉色，避免混用多個主色 |
| Border | 必要邊界 `1px solid #E6E8EB`；用於分隔，不給所有選項加外框 |
| Radius | 面板 `10–14px`；縮圖 `4–6px`；輸入區 `6–8px`；圓形主要留給快門／播放 |
| Shadow | 浮起面板 `0 6px 20px rgba(24,34,44,.05)`；普通列項／圖示無陰影 |
| Material | 不透明白色，不使用背景模糊、玻璃亮邊或彩色光暈 |
| Spacing | 4px 基準；面板內距 `24–32px`；大區塊間距 `32–40px`；設定列高 `40–44px` |
| Font | SF Pro／Helvetica Neue（需環境可用），中文 Noto Sans TC；400 為主，500 表示標題或選中；缺少字體時明確 fallback |
| Type scale | 頁面標題 `20–24px`；工具標籤 `12–13px`；設定值 `12px`；輔助資訊 `11–12px` |
| Text | 主要 `#272B30`；次要 `#687079`；低強調 `#737B84`，避免淡到不可讀 |
| Icon | `20–24px`，`1.25–1.5px` 描邊，round cap／join，單色、統一光學尺寸；通常沒有底座 |
| Selection | 小面積藍色圖示、短底線或細圈；不以整張大色卡表示選中 |

## 構圖應用

- 作品放在開放畫布上，窄工具列靠邊，設定使用簡單文字列；不把每一個區塊框成面板。
- AI 選擇可以是底部水平縮圖＋短標籤＋一條選中線，而不是固定右側三張聊天卡片。
- 尺規、對齊線、滑桿與選區框是精緻感來源。只保留任務需要的工具，不為了像相機添加無用途的讀數。
- 影像用自然攝影建立氣氛，避免 UI 本身大量裝飾。參考圖裡照片的粉色／藍色不必變成整套介面的底色。

## 常見失敗與檢查

- 失敗：到處圓角卡片、粗字、填色圖示、每個 icon 外面一個灰色方塊、把極簡理解成縮小所有文字。
- 檢查：移除陰影後層級是否仍清楚？圖示線寬是否一致？畫面是否有真正連續的留白？
- 細線是視覺風格，不代表小觸控區；正式可互動產品仍需足夠 hit area 和文字標籤。
- 桌面靜態稿縮到手機只是一張總覽，不視為手機版介面完成。
