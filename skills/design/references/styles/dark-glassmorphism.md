# Dark glassmorphism｜深色玻璃擬態

原圖：[AMPLIFY 音樂播放器](images/dark-glass-audio.png)、[滿版影像剪輯器](images/dark-glass-video.png)。先看圖片，再讀 tokens。

## 圖片觀察

- 音樂播放器：大塊玻璃容器跨越深藍、酒紅與白色背景光，面板內的色澤會隨背景改變。細亮邊、柔和陰影與較亮的內部列項建立層次；展示標題與功能文字有不同字體性格。
- 影像剪輯器：作品鋪滿主舞台，左側圓形工具、右側對話與底部時間軸疊在作品上。背景影像同時決定玻璃的暖色與明暗。
- 兩圖共同核心是「透色與深度」，不是深色底加藍紫卡片。播放器可有結構化側欄，影像編輯器適合更開放的浮層構圖，依任務選擇。

## 建議 style tokens（非原圖量測）

| 項目 | 建議起點 |
|---|---|
| 背景 | `#080D19`；搭配大範圍低頻率酒紅／冷藍光，或全幅作品影像 |
| 面板 | `rgba(22,28,44,.48)`；可依底圖亮度調整，不固定所有玻璃為同一深藍 |
| Blur | `backdrop-filter: blur(24px) saturate(130%)`；仍能感知底下色彩 |
| Border | `1px solid rgba(255,255,255,.20)`；受光側稍亮；內部分隔約 `.08–.12` |
| Radius | 外殼 `24–28px`；浮層 `18–22px`；選項列 `12–14px`；獨立工具圓形／膠囊 |
| Shadow | `0 24px 64px rgba(0,0,0,.36)`；可加 `inset 0 1px 0 rgba(255,255,255,.14)` |
| Spacing | 8px 基準；面板內距 `20–24px`，浮層間距 `16–20px`，相關控制 `8–12px` |
| Font | 功能 UI：Inter／Noto Sans TC，400–500；展示標題可少量用 Cinzel／Noto Serif TC，不把襯線套到所有操作 |
| Type scale | 展示 `28–36px`；面板標題 `15–16px`；內文 `13–14px`；資訊 `11–12px` |
| Text | 主要 `#F4F6FC`；次要 `#BAC3D5`。透明度只設在面板背景，不降低整個容器 opacity |
| Icon | `20–22px`，`1.5px` 線寬，白／淡灰；可有半透明圓形工具底 |
| Selection | 提亮玻璃＋細亮邊＋勾選；主操作可用白色實心，不做全介面霓虹光框 |

## 構圖應用

- 沉浸編輯器：作品覆蓋主要舞台；AI 對話窄浮層置右，工具沿左側，分鏡浮於下方。不要把作品縮到中央小卡後，另以三塊不透明側欄占滿畫面。
- 內容管理器：可使用一個大玻璃殼與內部分區，讓背景色自然穿過各區，避免每張卡片都是獨立發光物。
- 選項、按鈕、文字也要採同一材質語言，不只改頁面背景。

## 常見失敗與檢查

- 失敗：固定藍色面板、只加漸層、後方沒有任何可透出的內容、所有元素套 blur。
- 檢查：同一面板橫跨明暗背景時，是否真的呈現色澤差異？停用 blur 後，是否仍有可辨識的層級與足夠文字對比？
- 明亮圖片可能需要局部暗襯。不要為透明感犧牲閱讀；對比須在實際合成後的背景檢查。
- 截圖只能證明靜態材質，不能據此宣稱動態光效或互動已驗證。
